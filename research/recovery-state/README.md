# Recovery-state feasibility harness (research only)

**Status:** Synthetic feasibility prototype; no scientific validation or novelty claim.

This folder contains an intentionally small deterministic comparison of (A) an illustrative naive operational proxy and (B) an evidence-gated physical-state baseline. The naive proxy is NOT the actual CreteXchange production algorithm. The gated baseline is NOT a probabilistic model and does NOT establish a new computational invention.

Run in an isolated checkout: `node --import tsx --test tests/recovery-state-research.test.ts`.

All cases are synthetic. The reference outcomes are authored assumptions, not observed physical recovery. Agreement with synthetic labels is a unit-test sanity check, not evidence of accuracy, calibration, statistical significance, or NSF novelty.

The five state labels are research-only and must not be mapped into operational `verified` status, billing, rewards, or environmental claims.
