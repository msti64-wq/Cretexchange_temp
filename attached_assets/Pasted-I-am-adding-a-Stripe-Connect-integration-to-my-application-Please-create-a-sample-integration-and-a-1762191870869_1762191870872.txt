## Creating Connected Accounts
Create a connected account where the platform is responsible for pricing and fee collection.

When creating connected accounts, please use the following properties:

```js
     stripe.accounts.create({
      controller: {
        // Platform is responsible for pricing and fee collection
        fees: {
          payer: 'application' as const
        },
        // Platform is responsible for losses / refunds / chargebacks
        losses: {
          payments: 'application' as const
        },
        // Give them access to the express dashboard for management
        stripe_dashboard: {
          type: 'express' as const
        }
      }
    });
```
Only use controller properties when creating accounts. Never pass type at the top level. **Do not use top level type: 'express' or type: 'standard' or type 'custom'**

## Process Charges

```js

      application_fee_amount: 123,
```
