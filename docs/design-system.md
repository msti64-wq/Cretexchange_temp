# Design System

## Phase Summary

- Phase 1: foundation tokens and primitives
- Phase 2: admin dashboard applied
- Phase 3: owner pages applied
- Phase 4: driver pages applied

## Tokens

Current reusable token set:

- app background
- card background
- elevated background
- border
- primary text
- secondary text
- accent / primary action
- success
- warning
- danger
- info

## Components

- `DSCard`
- `DSKpiCard`
- `DSStatusChip`
- `DSSectionHeader`
- `DSTableShell`

## Usage Rules

- Use the primitives for new dashboard and accounting surfaces.
- Keep existing APIs and business logic unchanged when adopting the design system.
- Prefer the design-system shell components for reusable patterns rather than page-specific card markup.
