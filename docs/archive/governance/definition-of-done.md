# Definition of Done

## Purpose

This document defines the minimum standard required for CreteXchange work to be considered complete.

## Definition of Done

Every feature should satisfy:

- Vision alignment
- Product documentation updated
- Product decisions updated
- Architecture reviewed
- Operational impact understood
- `npm run check` passes
- `npm run build` passes
- Validation complete
- Audit complete
- Documentation complete
- Commit isolated
- Release notes updated when appropriate

## Maintenance Note

If a feature does not satisfy these conditions, it should not be treated as done even if the code compiles.
