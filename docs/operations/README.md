# CreteXchange Operations Library

This library contains reusable, approved operational procedures, checklists, templates, and release evidence records. It is governed by [CTX-STD-001](../standards/cretexchange-platform-standards.md), [CTX-DB-001](../standards/CTX-DB-001-database-migration-and-schema-governance-standard.md), [CTX-DEP-001](../standards/CTX-DEP-001-production-deployment-protocol.md), and [CTX-OPS-001](./CTX-OPS-001-production-release-checklist.md).
