# Changelog

## Purpose

This section records product milestones, release summaries, and notable changes across CreteXchange.

## What Belongs Here

- Product milestones
- V2 notes
- V2.5 notes
- V3 notes
- Release summaries
- Migration notes when relevant

## What Does Not Belong Here

- Current design rules
- Architecture diagrams
- API contracts
- Runtime code
- Day-to-day implementation notes that belong in development docs

## Planned Contents

- Release-by-release summaries
- Major feature launches
- Platform milestone notes
- Migration context when a release affects data or workflow
- High-level change records for future reference

## Maintenance Note

Update this folder when a change is important to remember later, not for every small commit. Prefer concise entries that explain what changed and why it mattered.
